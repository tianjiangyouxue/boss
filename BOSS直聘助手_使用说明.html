1这是什么

BOSS直聘助手是一个 Chrome 浏览器扩展，在 BOSS 直聘网页端自动完成简历筛选：

  • 自动逐份打开简历 → 截图 / OCR 识别内容 → AI 评分
  • 分数达标后自动执行：收藏、打招呼、邮件转发、生成分享卡片
  • 沟通页可批量下载简历附件、自动「求简历」
  • 分析结果存入浏览器本地数据库，支持筛选、导出、备份
环境说明：AI 识别与评分由公司内网服务器提供，请在能连通内网的环境使用。

2安装前准备

  1. Chrome 浏览器（建议 120 以上版本）
  2. 网络环境：必须能访问内网服务器 192.168.5.235（8866、8088 端口）
  3. 账号：已登录 BOSS 直聘企业账号（招聘者身份）
  4. 建议关闭其他同类插件（多个自动化插件同时运行容易互相干扰、增加风控风险）
  5. 不需要配置 API Key，DeepSeek 调用由内网后端代理
网络自检：浏览器打开 http://192.168.5.235:8866/health，看到 {"status":"ok","service":"RapidOCR","deepseek_proxy":true} 即正常。

3安装步骤

  1. 解压 dist.zip，得到 dist 文件夹
  2. Chrome 地址栏输入 chrome://extensions/
  3. 打开右上角 开发者模式
  4. 点击 加载已解压的扩展程序，选择 dist 文件夹（不要选外层解压目录）
  5. 安装成功，工具栏出现插件图标；建议点击拼图图标把它固定
插件更新后：在 chrome://extensions 点插件卡片上的「重新加载」，并刷新已打开的 BOSS 页面（旧页面里的注入代码不会自动更新）。

5开始分析

5.1 支持哪些页面

页面路径支持功能
推荐牛人/web/chat/recommend✅ AI 读简历（主要使用场景）
搜索 / 人才库/web/chat/search✅ AI 读简历
沟通 / 消息/web/chat/index⚠️ 不支持 AI 读简历；支持「下载简历附件」「求简历」

5.2 操作步骤

  1. 进入 BOSS 直聘的 推荐牛人 或 搜索 页面，确认简历列表已加载
  2. 点击插件图标，配置并保存设置
  3. 点击页面右下角（或插件面板上的）🔍 AI读简历 开始
  4. 插件自动执行：滚动列表 → 打开简历 → 截图识别 → AI 评分 → 达标动作 → 保存结果 → 关闭弹窗
  5. 随时按 ESC 或再次点击按钮停止

5.3 运行中的提示

页面底部左侧会出现状态条，例如：

  • AI正在筛选简历... —— 正常工作
  • ☕ 模拟真人休息 30 秒... —— 正常节奏控制（见第 6 节）
  • ⏸ 页面不可见，暂停中 —— 切走了标签页，切回来自动继续
  • ⏳ Boss限流，等待60秒... —— 触发了平台限流，自动等待恢复
  • ⏰ 已到 22:02，自动停止 —— 到达停止时段
  • 今日浏览100份已满 —— 达到每日上限
运行期间不要手动点击页面，避免与自动化流程冲突。需要停止请按 ESC。

6内置保护机制（重要，不是故障）

为防止账号被平台风控，插件内置了以下保护。遇到时请理解为正常行为：

机制行为
22:02 自动停止22:02 之后无法启动分析；运行中到点会自动停止。请在白天使用
页面不可见暂停切到其他标签页 / 最小化窗口时自动暂停，切回自动继续。请保持 BOSS 标签页在前台
单标签页锁同一时间只允许一个标签页运行自动化。其他标签页启动时会提示「另一个标签页正在运行」
随机读取顺序每轮打乱列表顺序处理，不按列表挨着读，模拟真人浏览
随机节奏操作间隔随机化；每处理 5–9 份随机休息 20–60 秒
限流自动等待检测到「查看太频繁」提示时自动等待 40–90 秒，连续限流等待时间翻倍
每日上限浏览 100 份 / 天、分享（邮件转发 / 求简历）100 次 / 天
DOM 特征伪装注入页面的元素类名每次构建随机化，降低被识别的概率
注意：这些措施只能降低风险，不能保证 100% 不被平台检测。请勿 24 小时连续运行、勿多设备同时跑同一账号。

7结果面板

分析开始后，页面右侧显示结果面板。

7.1 顶部操作

  • AI读简历：开始 / 停止分析
  • 仅显示达标简历：勾选后隐藏低分结果
  • 时间筛选：全部 / 今天 / 昨天 / 近7天 / 近30天（默认「全部」）
  • 简历库：查看已下载的附件简历与云链接

7.2 单条结果

  • 显示：姓名、年龄、公司、评分（绿色达标 / 红色未达标）
  • 图标按钮：定位到简历位置、下载简历文本
  • 点击姓名 / 展开箭头查看：评分明细、评价建议、简历截图、分享卡片、分析时间

7.3 底部按钮

按钮功能
下载 HTML导出完整分析报告（含评分明细、截图、分享卡片）
导出 Excel导出 CSV 表格（Excel 可直接打开）
备份将分析数据备份到本地文件（IndexedDB）
恢复从备份文件恢复分析数据
清空结果删除分析结果；可选择「仅清空结果」或「清空全部记录（含已分析标记）」
下载简历批量下载已解析的简历文本
数据位置：数据保存在浏览器本地（IndexedDB 数据库 hr_resume_db），不会自动上传。更换电脑或清理浏览器数据会丢失，重要数据请先「备份」。

8沟通页功能

在 沟通 / 消息 页面（/web/chat/index），插件面板提供：

8.1 下载简历附件

  • 遍历当前聊天列表，自动下载候选人发来的 PDF 附件
  • 同时自动上传到云盘（内网 192.168.5.235:8088），并在结果里记录云链接
  • 已有附件 / 已下载过的会自动跳过
  • 再次点击按钮 = 停止

8.2 求简历

  • 遍历未读对话：有附件则跳过；没有附件则点击「求简历」并确认
  • 每个请求消耗一次每日分享额度（上限 100）
  • 再次点击按钮 = 停止

8.3 简历库

  • 展示已下载的附件记录：文件名、候选人、本地 / 云链接、时间
  • 支持搜索、刷新、清空

9常见问题 FAQ

Q1：点击开始后毫无反应？

依次检查：① 是否在内网（打开 http://192.168.5.235:8866/health 验证）；② 是否在推荐 / 搜索页面；③ 是否已显示「另一个标签页正在运行」；④ 刷新页面后重试。

Q2：一直提示「页面不可见，暂停中」？

分析期间请保持 BOSS 标签页在前台，不要切走或最小化窗口。这是刻意设计，用于降低风控。

Q3：22:02 之后点开始没反应？

这是时段保护，次日白天可正常使用。

Q4：评分不准确？

在设置面板修改系统提示词（或选模板），把岗位要求、硬性条件、加分项写清楚。阈值建议 70–85。

Q5：提示「另一个标签页正在运行」？

同一浏览器只允许一个标签页跑自动化。关闭其他标签页，或等待约 5 分钟锁自动过期。

Q6：分享卡片偶尔串人 / 显示上一个人的？

已针对 BOSS 弹窗复用问题做了修复；如果仍出现，按 ESC 停止后刷新页面再开始。

Q7：转发弹窗关不掉 / 页面有灰色蒙版？

已修复（v0.2.0 最新构建）。若仍复现，请刷新页面；仍不行请反馈并附上控制台报错。

Q8：控制台出现 Executing inline event handler violates ... Content Security Policy？

这是 BOSS 页面自身的风控脚本（initWarlockData）被它自己的 CSP 阻止，与插件无关，可忽略。

Q9：附件下载失败？

确认在沟通页、候选人确实发送了 PDF 附件；网络慢时等待重试。下载记录可在「简历库」查看。

Q10：云上传链接打不开？

云链接指向内网 192.168.5.235:8080，需在内网环境打开。

Q11：如何彻底重置插件？

chrome://extensions 中移除插件 → 重新加载；或在插件面板「清空结果 → 清空全部记录」。历史分析标记保存在 chrome.storage.local 的 analyzedResumeIds，重新加载插件不会清除，需要手动「清空全部记录」。
